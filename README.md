# 🌦️ Clima Paraguay

Aplicación web desarrollada con Django que permite consultar el clima en tiempo real y visualizar el pronóstico extendido.

## 🚀 Funcionalidades

- Consulta de clima en tiempo real
- Pronóstico por horas y días
- Geolocalización automática
- Historial de consultas
- Favoritos
- Estadísticas simples
- Interfaz moderna y responsiva

## 🛠️ Tecnologías

- Python
- Django
- OpenWeather API
- Chart.js
- HTML, CSS, JavaScript
